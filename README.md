# ZUFE Thesis Toolkit · 组织主页与协作

这是 ZUFE Thesis Toolkit 的组织配置仓库。[`profile/README.md`](profile/README.md) 显示在 [GitHub 组织首页](https://github.com/zufe-thesis-toolkit)，介绍各工具及其获取方式。

| 文件 | 用途 |
| --- | --- |
| [`profile/README.md`](profile/README.md) | 组织首页：向用户介绍工具、当前状态和下载入口 |
| [`ROADMAP.md`](ROADMAP.md) | 套件路线图：各组件的交付顺序和验收条件 |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | 反馈与协作方式，可作为组织下各仓库的默认贡献指南 |

上游 LaTeX 模板由 [ZUFE-Thesis](https://github.com/sqsssq/ZUFE-Thesis) 独立维护。Quarto、Word/WPS 插件及 Desktop 按各自的开发和发布节奏推进。本仓库的 Issues 用于套件路线图、跨工具兼容和组织文档。
