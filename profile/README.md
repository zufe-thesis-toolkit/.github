# ZUFE Thesis Toolkit

为浙江财经大学毕业论文写作提供一套工具。你可以继续用熟悉的 LaTeX、Quarto、Word 或 WPS 写作；套件的目标是让不同工作流都能按同一套论文格式要求交付。

| 你习惯用什么写？ | 对应工具 | 当前状态 |
| --- | --- | --- |
| LaTeX | [ZUFE-Thesis 上游模板](https://github.com/sqsssq/ZUFE-Thesis) | 已公开，可前往[上游 Releases](https://github.com/sqsssq/ZUFE-Thesis/releases)获取 |
| Markdown / Quarto | ZUFE Thesis Quarto 扩展 | 已有 PDF 和 Word 导出版本，暂未开放公开下载 |
| Word / WPS | 分别面向 Word 和 WPS 的论文插件 | 规划中，优先做论文格式检查 |
| 希望从一个应用开始 | ZUFE Thesis Desktop | 规划中，提供工具选择、项目创建和导出入口 |

我们会先验证各工具的论文输出，再通过 Desktop 和统一的下载入口把它们组织成一个套件。各工具仍可独立使用。

[查看路线图](https://github.com/zufe-thesis-toolkit/.github/blob/main/ROADMAP.md) · [反馈套件建议](https://github.com/zufe-thesis-toolkit/.github/issues)

本项目由社区维护。学校的现行论文要求以学校及各学院发布的文件为准。
